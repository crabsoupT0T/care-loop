# Care Loop

Multi-agent AI system for coordinated healthcare and care workflows.

## Vision
Agents that handle triage, scheduling, follow-ups, family coordination, and resource matching with human-in-the-loop safeguards.

## Stack (planned)
- Python + LangGraph / CrewAI for agent orchestration
- FastAPI backend
- Next.js / React frontend
- Tool use for calendars, medical knowledge bases, messaging

## Getting Started
```bash
# Clone and setup
git clone https://github.com/crabsoupT0T/care-loop.git
cd care-loop
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
